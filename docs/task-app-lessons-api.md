# Задача: API-слой каталога уроков (api/lessons.ts + useLessons) + уборка LessonCard

Подготовительный слой для учебного каталога (interface-область `app`).
UI в этой задаче НЕ делаем — мокап каталога ещё не утверждён.
Задача маленькая и независимая: после неё фронт просто умеет запрашивать
уроки со статусом, ничего на экране не меняется.

## СТОП-проверка (перед началом)

Убедись, что `src/api/schema.d.ts` свежий и закоммичен:
в нём `/api/lessons/` отвечает `LessonWithStatus[]`, схемы `LessonCardOut`
больше нет. Если это не так — ОСТАНОВИСЬ и сообщи Jenna, ничего не делай.

## Контекст

- `GET /api/lessons/` теперь возвращает `list[LessonWithStatus]`:
  карточка урока + `status` и `watch_percent` текущего пользователя.
  Параметр `?category_id=` — только уроки этой категории (без подкатегорий).
- Псевдоним `LessonWithStatus` уже есть в `src/types/api.ts`.
- Псевдоним `LessonCard` теперь равен `LessonWithStatus` (два имени одного
  типа) — Jenna разрешила его удалить.

## Что сделать

### 1. `src/api/lessons.ts` — новый файл

По образцу ближайшего существующего файла в `src/api/` (например,
`categories.ts`): тот же клиент, тот же стиль обработки ответа.

- Одна функция: `listLessons(categoryId?: number): Promise<LessonWithStatus[]>`.
  Без `categoryId` — запрос `GET /api/lessons/`; с ним —
  `GET /api/lessons/?category_id={id}`.
- Никаких других функций (урок по id, прогресс и т.п.) — они появятся
  в задачах страницы урока. Не добавляй «на будущее».

### 2. `src/hooks/useLessons.ts` — новый хук

По образцу `useCategoriesTree` (паттерн «номер попытки» для reload,
без setState-в-эффекте):

- Сигнатура: `useLessons(categoryId?: number)`.
- Возвращает: `{ lessons, loading, error, reload }` — в том же стиле,
  что соседние хуки списков (`useUsersList` и т.п.): ошибка — состояние
  для страницы (покажем с Retry), не проглатывается.
- Смена `categoryId` перезапрашивает список.
- НИКАКОЙ логики ролей внутри хука: гейт по `activeRole` будет на
  странице каталога (как всегда — до запроса, а не ловля 403).
- НИКАКОЙ группировки по категориям внутри хука: раскладка по группам —
  дело будущей страницы каталога (по образцу таблицы уроков Content).

### 3. Удалить псевдоним `LessonCard` из `src/types/api.ts`

- Ровно одна строка. Перед удалением проверь поиском по репо, что
  `LessonCard` нигде не используется (по нашим данным — нигде).
  Если вдруг используется — ОСТАНОВИСЬ и сообщи, не удаляй.

UI нет, поэтому проверка короткая:

1. `cd frontend && npm run build` — сборка проходит без ошибок.
2. `npm run lint` — чисто.
3. Поиск в VS Code по `LessonCard` (весь frontend/src) — 0 совпадений.
4. Открыть `src/api/lessons.ts` и `src/hooks/useLessons.ts` глазами:
   стиль совпадает с соседями (categories.ts, useCategoriesTree).
