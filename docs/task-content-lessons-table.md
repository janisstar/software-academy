# Задача: страница Content / Lessons — таблица (часть 1 из 2)

## Контекст

Master-таблица всех уроков платформы. Мокап УТВЕРЖДЁН:
`docs/mockups/content-lessons-mockup-v2.html`, экраны 1 (таблица)
и 2 (пустое состояние). Экраны 3–4 (форма урока) — СЛЕДУЮЩАЯ задача,
в этой НЕ делать.

Выполняется ПОСЛЕ task-design-radius-and-select (кнопки/чипы уже
на --radius-xs, Select уже со своей стрелкой — здесь про это ничего
делать не надо).

Эндпоинты:

- `GET /api/master/lessons/` → `list[MasterLessonOut]`
  (id, title, slug, category_id, vimeo_id, duration_seconds,
  is_public, roles: ключи, order, created_at). Отсортирован бэком.
- `GET /api/categories/` → дерево (для имён и порядка групп).
- `POST /api/lesson/move/` → `{id, direction: "up" | "down"}`.
- `GET /api/roles/` — имена ролей (через существующий useDirectories).

## Доступ

Только master: гейт по `activeRole` до запросов (как Categories),
не-master по прямому URL — заглушка «In development». navConfig уже
скрывает Content от не-master (сделано в прошлой задаче) — не трогать.

## Отображение

### Группировка по категориям

Уроки группируются ПО ДАННЫМ ДВУХ эндпоинтов, без клиентской
арифметики порядка:

1. Порядок групп = обход дерева `GET /api/categories/` как есть:
   верхний уровень в порядке ответа, после каждого родителя — его
   subcategories в порядке ответа.
2. Уроки раскладываются по группам по `category_id`; внутри группы —
   в порядке ответа master-эндпоинта (он уже по order). НЕ сортировать.
3. Заголовок группы: имя категории; для подкатегории —
   «Родитель / Подкатегория». Пустые категории (без уроков)
   в таблице НЕ показываются.
4. Урок с category_id, которого нет в дереве (теоретически
   невозможно) — группа «Unknown category» в конце, чтобы данные
   не потерялись молча.

### Колонки (по мокапу)

▲▼ | Lesson (title) | Duration | Visibility | Vimeo ID | Created

- Duration: `duration_seconds` → «m:ss» (4:20). 0 → «0:00».
- Visibility: `is_public` → чип Public (accent-tint);
  иначе roles не пусты → чипы ролей (существующий RoleChip,
  имена из useDirectories по ключу);
  иначе → чип Hidden (ink-токены). Подпись под таблицей из мокапа
  (что такое Hidden).
- Vimeo ID — моноширинным (ui-monospace), Created — формат дат
  как в UsersTable (переиспользовать существующую утилиту/формат).
- Строка кликабельна → `/content/lessons/:id`; курсор pointer,
  hover-фон как в мокапе. Клик по ▲▼ НЕ должен открывать урок
  (stopPropagation).

### Порядок ▲▼

- Ряд соседей = уроки ТОЙ ЖЕ категории. ▲ disabled у первого
  в группе, ▼ у последнего.
- Клик → `POST /api/lesson/move/` → reload списка. Без оптимистичных
  перестановок. Ответ noop — ничего не делать.
- Пока запрос летит — обе кнопки строки disabled.

### Фильтр по категории

Селект над таблицей (существующий Select): «All categories» + все
категории дерева (подкатегории как «Родитель / Подкатегория»).
Клиентская фильтрация по `category_id` (выбор родителя показывает
ТОЛЬКО его собственные уроки, не уроки подкатегорий — просто и
предсказуемо). При активном фильтре ▲▼ продолжают работать —
ряд соседей от фильтра не зависит (он и так в пределах категории).

### Шапка и переходы

PageShell: h1 Lessons, caption и кнопка «Add lesson» из мокапа.
«Add lesson» → `/content/lessons/new`.

Роуты `/content/lessons/new` и `/content/lessons/:id` создать
СТРАНИЦАМИ-ЗАГЛУШКАМИ (PageShell + «In development» + ссылка
«← Back to lessons») — форма будет следующей задачей, но переходы
должны работать уже сейчас.

### Пустое состояние

Экран 2 мокапа. Кнопка «Add lesson» в нём ведёт туда же.

## Testing guide (напиши свой по этому скелету)

Dev, вход keimo, в базе — категории и уроки из Swagger-тестов.

1. /content/lessons: группы в порядке дерева категорий, подкатегория
   подписана «Родитель / Подкатегория», внутри групп порядок по order.
2. Visibility: урок public → Public; урок с ролями → чипы с именами
   с бэка (Welder!); урок без ролей и не public → Hidden.
3. ▲▼ внутри группы, края погашены, после клика порядок обновился;
   клик по стрелке НЕ открывает урок.
4. Фильтр: выбор категории оставляет только её уроки; All возвращает.
5. Клик по строке → заглушка /content/lessons/:id; Add lesson →
   заглушка /new; «Back to lessons» возвращает.
6. Пустая база уроков → empty state.
7. Не-master: прямой URL → заглушка, Network без запросов.
